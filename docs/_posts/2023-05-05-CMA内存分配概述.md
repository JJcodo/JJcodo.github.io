# CMA内存

CMA （Contiguous Memory Allocator） 是Linux内核中用于分配大块连续物理内存



1、CMA区域的内存在没有被驱动使用的时候，会被buddy系统复用，分配给Movable的申请或者带有GPF_CMA标识的申请（匿名页或者zram的页），当驱动申请的时候，他会把这些页迁移出去，将CMA区域的内存腾给驱动使用。

2、CMA使用bitmap管理每块CMA连续内存，当这块内存被分配出去的时候，相应的page就会被置位。

cma_bitmap_aligned_mask函数

```c
// cma_bitmap_aligned_mask函数是用于计算位图掩码的函数，这个掩码可以确保在连续内存分配（CMA）过程中分配的内存块满足对齐要求。那么什么是对齐？order_per_bit的含义是用于每个位所对应的连续页数
static unsigned long cma_bitmap_aligned_mask(const struct cma *cma,
					     unsigned int align_order)
{
	if (align_order <= cma->order_per_bit)
		return 0;
	return (1UL << (align_order - cma->order_per_bit)) - 1;
}
```

cma_bitmap_aligned_offset函数

```c
// cma_bitmap_aligned_offset函数用于计算与指定对齐要求相匹配的位图偏移量
static unsigned long cma_bitmap_aligned_offset(const struct cma *cma,
					       unsigned int align_order)
{
	return (cma->base_pfn & ((1UL << align_order) - 1))
		>> cma->order_per_bit;
}
```
