# 动态规划刷题

### 1、爬楼梯

f(x)表示爬到x级台阶的方案数，由于最后一步爬了两阶，也可能爬了一阶，则可以列出函数关系f(x) = f(x-1) + f(x-2) 

因此得出递归解法

```c++
// 递归解法
// 这个解法会超时，开销很大
int climbStairs(int n) {
	if (n >= 3) {
		return climbStairs(n-1) + climbStairs(n-2);
	} else if (n == 2) {
		return 2;
	} else if (n == 1) {
		return 2;
	} else {
		return 0;
	}
}
```

将递归解法转化成循环

```c++
// 循环解法 将递归解法转化成循环。
int climbStairs(int n) {
	int f1 = 1, f2 = 2, f;
	if (n == 1) {
		return f1;
	}
	if (n == 2) {
		return f2;
	}
	for (int i = 3; i <= n; i++) {
		f = f1 + f2;
		f1 = f2;
		f2 = f;
	}
	return f;
}
```
